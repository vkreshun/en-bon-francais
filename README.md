# En bon français

Сайт преподавателя французского языка Кристиана: индивидуальные онлайн-уроки, подготовка к DELF/DALF.

Статический сайт (HTML/CSS/JS), публикуется через GitHub Pages.

- Контакты, ссылки и материалы настраиваются в начале `script.js`.
- Раздел «Материалы» включается переключателем `SHOW_MATERIALS = true` в `script.js`.
